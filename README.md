# AutoSpaceTestTask

###Требования к тестовому заданию: 
1. Необходимо разработать БД, которая позволит хранить магазины и товары магазинов.
Описание сущностей:
Магазин: код, наименование, адрес, режим работы.
Товар: код, артикул, бренд, название, группа.

2. Нужно сделать веб страницу, которая будет выводить список магазинов в виде таблицы.
В каждой строчке должна быть ссылка на товары магазина и кнопка "редактировать магазин" при клике на которую в модальном окне возможность изменить данные выбранного магазина.
По нажатии на ссылку отображение товаров магазина в виде таблицы.
Получение данных из БД необходимо реализовать с помощью LINQ.
Реализовать подсветку строки таблицы, на которую наведен курсор.

3. Отдельная кнопка "Магазины работают сейчас" при клике откроется модальное окно, в котором отобразится список магазинов которые работают в данный момент, с возможностью перейти в другую модалку с отображением всей информации по магазину и кол-ву товаров

### Реализация
Веб-приложение на ASP.NET Core с базой данных SQL Server, разворачиваемое в Docker.

## Требования к развертыванию

- Установленные **Docker** и **Docker Compose** (версия 3.9 или выше)
- Порт **5000** (веб-приложение) и **1433** (SQL Server) должны быть свободны

## Переменные окружения

Замените при желании в файле `.env` в корне проекта значения пароля для учетной записи администратора в развертываемой базе на более надежное.

Пароль замените следующим образом 

SA_PASSWORD: _your_password_

ConnectionStrings__DefaultConnection=Server=db;Database=AsStorageDb;User Id=sa;Password=_your_password_;TrustServerCertificate=True;


В корневой папке проекта в консоли выполните команду docker compose up
